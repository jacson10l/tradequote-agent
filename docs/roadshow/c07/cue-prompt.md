# Cue 制作提示词

请根据同目录 roadshow.md、README.md、inquiry.md、expected.json 和实际验收截图，为TradeQuote制作一份中文、约4分钟、8页的项目路演，做成cue deck。

受众为项目评审及潜在业务使用者。采用原创的浅色暖橙视觉，文字少、字号大，以“业务员收到一封询盘→查资料补缺项→核价保存→数量修改比较→复制客户回复”为主线。标题“把一封询盘，变成一份有依据的报价”。每页附对应讲者备注，方向键能翻页；页面不得出现demo、harness、内部模型连接说明或内核徽章。

沿用本包基于A采集CSV整理的服装询报价案例，清楚区分商品来源与编写的询盘、条款。300件T恤每件39.21CNY，商品合计11763.00CNY；500件每件37.21CNY，商品合计18605.00CNY，合计增加6842.00CNY。运税费未知，不报0，不写落地总价。条款为拟议条件、待供应商确认；目录有效期不是供应商承诺，页面认证标签未核验。案例页须标“采集资料待审核；询盘为编写案例”。

禁止虚构客户、供应商背书、收入、市场规模、效率数字、认证或业务规则全覆盖。实际截图来自工作台；无实际执行证据的画面标“流程示意”，不伪装成实时软件。源码预览检查通过后再提供Cue查看链接，保持草稿/私人预览，未经另行授权不要公开发布或邀请第三方。

收尾明确：原始快照/有效期、条款/规则业务复核、正式审批/外发/PDF尚待完成。产品价值来自可核对的报价闭环，不能把待审核资料包装成已商业落地。
