## 来源与假设

A提供的是“真实采集、真实性待审核”的页面资料；本包没有重新访问供应商或完成业务签认。保留A补充的供应商、来源URL、采集日期、材质/比例缺项和CE待核验说明。`source-manifest.json`记录固定blob、SHA-256及两款服装的字段映射；板材/紧固件字段依据仍指向A归档。服装原始快照仍缺，目录有效期沿用A转换值，不等于供应商承诺。

询盘及交易条件由C编写，是贴近实际操作的案例，不是真实客户订单。不要把页面价写成当前有效承诺价，不要把拟议付款/交期、认证原文或平台惯例写成已确认事实。
