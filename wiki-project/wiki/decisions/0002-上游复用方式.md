# 0002-上游复用方式

## 背景

三名开发者均熟悉 TS/React，用户允许优先评估复用并按实测替换。首版为 Electron 本地桌面，未来接共享服务器。

## 决定

Solivio 不整体 Fork，两个实验候选不进入生产；CSV 采用 csv-parse 7.0.3，金额采用 decimal.js 10.6.0，自建跨品类映射、定价与版本契约。Harness 有条件复用官方 SDK/runtime/tools 0.2.1-rc.2，采用自有 profile 与业务桥接，不 Fork 内核。

## 替代方案

整体移植 Solivio 将引入 Next/Postgres 等边界调整；直接复制 parser/totals 无法满足当前损坏输入、locale 与 decimal 契约。最小受控执行器保留为 Harness 关键关卡不通过时的替代，不提前重写已验证机制。

## 后果

Harness 活动 run 独占进程，取消关闭进程；宿主掌握权限和业务幂等。Messages API/严格 DTO 需适配；preview、体积、打包与真实模型仍有风险。OTel API 覆盖到 1.9.1 的原因与实验结果见 [[技术验证记录]]。发布包没有可查询 gitHead，源码 commit 与 npm 版本分别记录。

## 回滚方式

AgentRuntime 保持项目端口；若真实模型或双平台必需关卡失败，更换执行器并保持 QuoteService/知识端口不变。回退时保留已提交版本、业务运行记录与迁移方案；不直接回放已完成写工具。
