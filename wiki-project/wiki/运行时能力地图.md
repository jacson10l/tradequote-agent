# 运行时能力地图

## 当前正式 M1 能力

preload 开放工作区三方法及 getTrade/saveScenario/stageCatalog/publishCatalog/createQuoteV1/pickCatalogCsv；严格 schema 与宿主来源校验后进入同一 SQLite 单写入服务。已支持场景版本、CSV 人工发布与手工草稿 V1 重开/幂等，详见 [[M2真实报价V1]]。场景/资料发布仍只允许 human_ui；正式 Agent 已通过 agent.understand/agent.revise 进入受限业务服务，详见 [[M4模型与报价修订]]。进程边界见 [[M1工程基线]]、[[M1接口与持久化]]。

## 历史实验能力

> 2026-10-21 本轮增量见 [[M0平台验证记录]] 与 [[0004-M0平台与执行器选型]]：新增真实 Electron/SQLite/解析/PDF/设置页探针；Harness 在当前 Electron 版本失败，默认切最小执行器。下文原 M0-reuse 结果保留其历史作用域。安装/双平台验收按用户决定暂缓。


| 能力 | 输入与输出 | 实现/限制 |
|---|---|---|
| search_catalog | query → 合成 SKU/单价/币种/来源 | 固定阀门 fixture，不能作为跨品类检索验收 |
| calculate_quote | sku、字符串 quantity → calculationId/total | 宿主 Decimal 计算 3×0.10；完整两种定价未实现 |
| create_quote_revision | calculationId、expectedVersion → 草稿 revision | 宿主内存 Map 去重，身份与操作键由宿主掌握 |
| session/resume | sessionId → 恢复 handle | 同一 dshHome，恢复缺失会话必须报错 |
| 取消 | 关闭独占 runtime → pending 拒绝 | 没有单会话 cancel；一次只支持一个活动运行拥有进程 |
| 检查与证据 | 固定场景 → JSON/TAP、退出码 | 运行目录与日志路径见配置页 |

源码注册点为 `experiments/m0-reuse/business-tools.mjs:5`；桥接拒绝未知字段，绑定取消信号。每次模拟模型请求断言工具集合严格等于三个业务工具。根参数对象的开放行为是上游 DSL 特性，额外字段必须由项目桥接拒绝。

profile 禁用 shell、文件工具、工作目录工具和 MCP，保留 session 工作目录服务及内部文件持久化。工具限制不能证明 OS 沙箱隔离；可信插件仍能用自身 Node 权限。这里不开放用户任意插件路径。

生成的 [[命令与运行时清单]] 是受限正则和 manifest 抽取，未解析动态注册或第三方包内部能力。产品最终 allowlist/权限契约见 [[04-接口与Agent契约]]；执行链路见 [[核心业务流程]]。


## 正式模型与两轮修订增量

公开桥新增modelSettings、understandInquiry、reviseQuote；Main设置白名单+凭据注入，Worker AgentExecutor只能提交理解/三类修改，无通用invoke/模型可用发布或审批工具。并发模型限制2个请求、同key共用执行；旧查询/手工业务可继续响应。 细节与当前边界见 [[M4模型与报价修订]]，本轮验证见 [[2026-10-21-正式模型与两轮修订]]。

## 工具循环的当前层级

C02a的ReadToolRuntime是可执行内部模块：JSON动作→已注册业务handler→下一模型请求，具备输入/结果schema、调用次数/完整上下文/总deadline和取消边界。测试已用现有SQLite目录与Decimal计算；生产worker仍调用旧AgentExecutor，没有注册通用工具或新IPC，六个允许工具名并不等于六个服务已接入。只读循环/生产适配/持久写工具/事件/桌面恢复分别为C02a/C02b/C02c/C03/C01b-c；逐项目标、依赖和完成范围见 [[双参考项目功能对照与C开发路线]]、[[C02a-受限只读工具循环]]。
