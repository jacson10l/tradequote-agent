# 运行时能力地图

| 能力 | 输入与输出 | 实现/限制 |
|---|---|---|
| search_catalog | query → 合成 SKU/单价/币种/来源 | 固定阀门 fixture，不能作为跨品类检索验收 |
| calculate_quote | sku、字符串 quantity → calculationId/total | 宿主 Decimal 计算 3×0.10；完整两种定价未实现 |
| create_quote_revision | calculationId、expectedVersion → 草稿 revision | 宿主内存 Map 去重，身份与操作键由宿主掌握 |
| session/resume | sessionId → 恢复 handle | 同一 dshHome，恢复缺失会话必须报错 |
| 取消 | 关闭独占 runtime → pending 拒绝 | 没有单会话 cancel；一次只支持一个活动运行拥有进程 |
| 检查与证据 | 固定场景 → JSON/TAP、退出码 | 运行目录与日志路径见配置页 |

源码注册点为 `experiments/m0-reuse/business-tools.mjs:5`；桥接拒绝未知字段，绑定取消信号。每次模拟模型请求断言工具集合严格等于三个业务工具。根参数对象的开放行为是上游 DSL 特性，额外字段必须由项目桥接拒绝。

profile 禁用 shell、文件工具、工作目录工具和 MCP，保留 session 工作目录服务及内部文件持久化。工具限制不能证明 OS 沙箱隔离；可信插件仍能用自身 Node 权限。这里不开放用户任意插件路径。

生成的 [[命令与运行时清单]] 是受限正则和 manifest 抽取，未解析动态注册或第三方包内部能力。产品最终 allowlist/权限契约见 [[04-接口与Agent契约]]；执行链路见 [[核心业务流程]]。
