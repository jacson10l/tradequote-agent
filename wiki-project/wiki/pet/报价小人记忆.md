# 报价小人记忆

本页是 TradeQuote 虚拟形象（报价小人）的**记忆板块**，属于项目知识库（`wiki-project`）的独立板块，随 git 版本管理。与 [[报价小人人设]] 共同构成小人的记忆存储。

## 板块结构

| 文档 | 内容 | 维护方式 |
|---|---|---|
| [[报价小人人设]] | 固定人格、视觉、性格、口头禅 | 人工维护，版本化 |
| 本页 | 对话中沉淀的长期记忆（偏好、称呼、约定） | 追加式，人工复核 |

## 记忆范围与边界

- 只记与「陪伴 / 产品使用 / 用户偏好」相关的轻量事实：用户称呼、语言偏好、常用商品品类、对小人语气的好恶等。
- **不记**任何报价、金额、客户、账本、审批等业务敏感数据——那些是业务 Agent 与数据库的职责，小人记忆不越界。
- 金额一律由确定性模块计算，未知不等于零；小人记忆不推算、不编造业务事实。

## 长期记忆

- （暂无长期记忆。首次与用户对话后，重要偏好会沉淀到这里。）

## 运行时实现说明

- 运行时会话记忆（高频 fact / 摘要）由 `packages/infrastructure/src/pet-memory-store.ts` 的独立 `pet-memory.db` 承载（有界滚动 MAX=100、fact≥30 压缩为 summary）。
- 本页是记忆板块的**长期、可见、进 git** 的沉淀载体；db 是会话态缓存，两者定位不同、互不冲突。
- 重要长期记忆由人工（或后续自动导出）从 db 沉淀到本页，形成可版本管理的知识。
