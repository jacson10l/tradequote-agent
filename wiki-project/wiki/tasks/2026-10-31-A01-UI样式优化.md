# 2026-10-31-A01-UI 样式优化

## 目标

按用户「整个页面字都要看得清、太小的统一调大一点」「保留橙黄基调但不要大片留白、改成浅灰层次」「科技感强的工具」的要求，对桌面渲染层做小样式优化，消除空洞感、提升可读性与精密感。全程不涉及业务逻辑、不新增依赖、不改配色品牌主色。

## 范围

仅改 `apps/desktop/src/renderer/src/App.tsx`（图标）、`theme.css`（配色 token + 组件样式）、`features/workspace.tsx`（布局 class）。共三处提交：`8eccee1`（图标 + hover + 字号）、`155a857`（表格表头圆角）、`8cb85c7`（工作区居中 + 暖灰配色 + 徽章/等宽数字/过渡）。

## 改动

1. **模型设置导航图标**（`8eccee1`）：`Settings`(齿轮) → `Cpu`(芯片)，语义更贴合「模型/算力」，与「工作区设置」齿轮区分。
2. **导航 hover 反馈**（`8eccee1`）：`nav a:hover` 新增浅灰背景，active 项 hover 保持高亮不闪烁。
3. **字号可读性**（`8eccee1`）：`small` 13px、`label` 14px、`.brand small`/`.sidebar-footer`/`.status-badge` 11→12px、`table` 12→13px。
4. **表格表头圆角**（`155a857`）：`table` 改 `separate` + `border-radius:8px` + `overflow:hidden`，表头灰底跟随卡片圆角裁切；`.table-scroll` 加 1px 内边距。
5. **工作区设置页居中**（`8cb85c7`）：`panel max-w-2xl` → `panel max-w-md mx-auto my-auto`，收窄并水平垂直居中。
6. **暖灰配色层次**（`8cb85c7`）：`--canvas` `#fffaeb`→`#f2efe9`、`--surface-muted` `#fafafa`→`#f5f3ef`、`--border` `#e5e5e5`→`#e8e5df`、`--surface-warm` `#fff8e0`→`#fff4e0`；白卡片 `.panel` 加 `box-shadow` 浮起。橙黄品牌强调（顶边条/按钮/选中态/TQ 标记）保持不变。
7. **徽章 + 等宽数字 + 过渡**（`8cb85c7`）：`.status-badge` 改胶囊形 + 圆点（`::before`）；`.basis`/`.basis strong` 加 `tabular-nums`；按钮/输入/链接加 120ms 过渡。

## 验收

- 模型设置使用芯片图标，工作区设置继续使用齿轮图标；侧边栏 hover 有浅灰反馈，active 项 hover 保持原高亮。
- 表格表头与卡片边缘圆角衔接，工作区设置内容水平垂直居中，暖灰背景与白色卡片形成层次。
- 小字号辅助文本、表单标签、状态徽章和表格正文均提升可读性；金额与依据数字使用等宽数字显示。
- 改动只影响渲染层样式，不改变报价计算、来源、契约、持久化或模型调用行为。
