# 虚拟形象看板娘

## 目标

为 TradeQuote 询报价工作台增加一个橙色暖色调、科技感的 2D Q 版看板娘（报价小人），作为品牌门面与轻量陪聊伙伴，拥有独立记忆板块；胸前标识为「报价单 + 上升折线」品牌 Logo（非闪电/充电），并接入 DeepSeek 模型头像与独立对话入口。

## 范围

- 载体为现有 Electron＋React 桌面应用（`apps/desktop`），不另起独立桌宠进程。
- 视觉层（Phase 0）：圆形头像 `pet-avatar.png` 替换 DeepSeek 模型头像；趴姿小人 `pet-mascot.png` 贴工作台对话面板旁。
- 记忆层（Phase 1）：独立 `pet-memory.db`，人设人工审核、会话记忆有界滚动 + 摘要压缩。
- 对话层（Phase 2）：小人专属对话入口 `/pet`，多轮历史 + 只读报价摘要注入。
- 润色层（Phase 3）：待机动画、表情状态联动、按住说话语音转写。
- 记忆板块落在项目知识库 `wiki-project/wiki/pet/`（人设 + 长期记忆，进 git）。

## 验收

- `tsc --noEmit` 退出码 0；改动文件 biome 全过。
- pet-memory-store / pet-quote-context 单测全过（9 项）。
- `electron-vite build` 成功，renderer 产物含 pet-avatar / pet-mascot。

- 契约：`packages/contracts/src/pet.ts`（PetPersona / PetMemoryItem / PetCommand / PetClient）。

- 主进程/preload：`apps/desktop/src/main/index.ts` 注册 `pet.*` 4 个 IPC；`preload/index.ts` 暴露 4 个 client 方法。
- 渲染层：`pet-assistant.tsx`（对话页）、`pet-mascot.tsx`（看板娘组件）、`use-speech-recognition.ts`（语音）、`App.tsx` 增 `/pet` 路由、`theme.css` 增动画与样式。

- 知识板块：`wiki-project/wiki/pet/报价小人人设.md`、`报价小人记忆.md`。
