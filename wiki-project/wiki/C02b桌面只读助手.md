# C02b 桌面只读助手

## 实际使用

在本任务工作树运行pnpm dev（或重新构建后启动本分支桌面），侧栏进入“只读助手”。先在“模型设置”保存账户可用的Key/模型ID，在“资料与报价”保存场景、确认发布商品。页面选择允许读取的一个报价版本；也可选择不读报价，仅使用商品。输入例如“查询DEMO-TEE并读取其价格来源，核算120件；对照所选报价金额”，点击“运行只读任务”。

运行会把任务和工具查询到的商品/所选报价发给已配置模型；页面事前说明发送范围。只读任务默认最多8次工具、120秒，Provider单请求45秒；缺场景时不注册核价工具，没有商品/所选报价时提交禁用。运行期间禁用重复提交和范围修改，无进度百分比、自动重试或自动模型测试。结果只在当前页面会话保留，重开不自动重发。

本轮已将四个真实handler接入正式Worker/Main/preload/UI；不再只是测试闭包或无生产调用方的内部模块。知识和规则仍未注册，真实DeepSeek效果仍需单独配置后评估。使用和验证不等于完整持久运行、取消或审批能力完成。

## 公开协议与进程边界

新增独立strict命令agent.read：schemaVersion=1、requestId、payload.instruction（1～8000字）、quoteRevisionIds（最多50个唯一ID，默认空）、可选productIds（最多500个唯一ID）。这是人工发起的只读任务，不带写幂等键，不接受workspaceId、asOf、credentials、工具集、价格/权限或路径注入。字段/类型集中在contracts/read-tools.ts，原C02b内部投影改为复用这里的schema，没有复制DTO。

Renderer → DesktopClient.readAgent → preload校验 → Main信任来源/主frame/URL/method白名单 → WorkerRequestSchema → CatalogQuoteReadService → CatalogQuoteReadAgent → 现有read/trade.get与确定性calculateQuoteV1。Main从模型设置取凭据，放入内部Worker消息；renderer结果、数据库、来源与工具上下文均不回传Key。模型端点仍固定，环回HTTP只在原有未打包且隔离测试条件下启用。

Worker由repository.read生成workspaceId、宿主时钟生成UTC asOf。renderer选择报价ID只代表本机用户授权此次读取，模型没有修改scope入口。知识/规则仍无新IPC：旧B00能力门禁保持，公开只读观测联合也只允许四种工具。原agent.understand/revise继续原来的TradeResult和保存行为。

| 层 | 当前行为 |
|---|---|
| 公共结果 | AgentReadResult成功data为completed/summary或waiting_input/clarification，含workspaceId/asOf/toolCalls/observations；计数须等于观测数，成功结果日期一致，报价工作区一致；拒绝committedRevisionId/approved等伪造写入事实 |
| 工具结果 | 四类strict观测保留实际查询/预览、公开失败、evidenceIds、来源hash/价格行；UI直接展示，不能用模型说明替代事实 |
| 进程内限流 | 一次一个只读任务，同requestId同payload的并发请求共享promise；同ID异参冲突，其他只读任务返回忙。结束后显式再次请求会重新调用模型；不持久缓存，不承诺跨重启或响应丢失后的计费恰好一次 |
| 等待与断线 | BusinessWorker对agent.read等待135秒，高于运行120秒预算；旧Agent仍60秒、普通业务15秒。超时/进程退出不重发，返回只读失败与可能再次收费说明，不沿用“保存未知”的提示 |
| 只读范围 | 宿主快照、商品范围、授权精确报价、未保存核价语义沿用 [[C02b商品与报价只读工具]]；不调用commitAgent/quote.createV1，不新增迁移或运行表 |

## 页面反馈与结果

首个业务面板直接展示任务与范围，无独占页头；统一共享Button/message/Notification。加载查询失败可手动刷新；运行异常清除旧结果，显示失败状态，不自动收费重试。长时间运行禁用提交和选择器，保留明确运行文字。模型说明及澄清按纯文本展示，无HTML执行。

工具结果分“商品检索/商品快照/报价读取/核价预览”展示：商品保留sourceStatus、有效期、档位和来源行，SHA-256可展开；旧报价显示Vn和读取时是否最新，保持原始金额；预览明确“未保存报价”，无保存身份、审批或导出按钮。实际失败显示错误码和说明，空成功显示未命中；零工具时提示缺少业务查询依据。表格文本左对齐，数量/金额右对齐，900px窗口图标导航仍可达。

“任务已结束”仅表示模型结束当前只读任务，不表示所有工具成功或报价已保存。模型summary、工具失败和未保存预览分别展示。后台失败或业务读失败不能显示成已保存新版本。
