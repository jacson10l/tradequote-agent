# 配置路径与敏感信息

> 2026-10-21 本轮增量见 [[M0平台验证记录]] 与 [[0004-M0平台与执行器选型]]：新增真实 Electron/SQLite/解析/PDF/设置页探针；Harness 在当前 Electron 版本失败，默认切最小执行器。下文原 M0-reuse 结果保留其历史作用域。安装/双平台验收按用户决定暂缓。


| 配置/路径 | 当前行为 | 敏感边界 |
|---|---|---|
| DEEPSEEK_API_KEY | 探针子进程明确传合成字符串 | 不读取真实 Key，不代表真实连接配置成功 |
| DEEPSEEK_MODEL | 证据收集器只检查变量名是否存在 | 实际路由 fixture 名由探针固定 |
| M0_BUSINESS_URL | 环回随机端口＋/business | 不向外部网络发送请求 |
| M0_BRIDGE_TOKEN | 宿主随机生成，插件请求鉴权 | 不入证据；模型无法提供身份 |
| PATH | 启动子进程所需系统路径 | 模型不获得 shell 工具 |
| `.runtime/harness-*` | 临时 profile、dshHome、会话 | gitignore 排除；Wiki 不遍历读取 |
| `experiments/m0-reuse/evidence/` | 合成摘要/测试输出/指纹 | 只纳管已阅读的显式日志文件 |
| `wiki-project/raw/generated/` | 可重建索引 | 不复制原始源码内容；固定基线 |

生成器在读取内容前按名称排除 .env、私钥、认证文件、数据库、依赖与缓存，并跳过所有符号链接。Wiki 自身不当作业务源码采集；维护工具有独立指纹。源文件引用也必须留在项目内且不经过符号链接。

lint 扫描纳管源码、维护脚本与自有 Wiki；原样外部归档仅核对 hash、索引可达与文件名，不将其示例链接当作项目链接。疑似 API token/JWT/私钥/个人信息只输出路径和规则，不回显值。规则不是完整隐私证明，存在误报时核对来源，不全局关闭检测。

Git 忽略依赖、会话、普通日志、凭据配置、私钥、数据库、构建目录和安装包；仅对逐项审阅过的 M0 合成日志及 Wiki 测试输出显式放行。Obsidian app.json 是共享配置，workspace/cache 等本机状态不提交。忽略规则不能替代提交前内容检查。

首次本地成果提交前，来源登记与采集基线中的本机绝对路径已脱敏，原始归档及其 hash 保持不变。显式 --ingest 仍记录本机路径，提交前须复查脱敏；普通 generate/check/lint 不恢复这些路径。

正式凭据设置/加密已在 [[M4模型与报价修订]] 实现，真实账户/Windows/签名迁移尚未验收。未来界面不得从模型输入接收工作区权限或幂等上下文。边界见 [[运行时能力地图]]，维护范围见 [[知识库可靠性与覆盖范围]]。
