# M1工作台

正式 Electron 现有单据布局预览、工作区设置、资料与报价、模型设置四条路由。模型设置是正式 React/TypeScript 界面，safeStorage 经 Main 隔离；不要求用户贴 Key，M0 HTML 页保留为独立历史探针。

DESIGN.md 的奶油背景、白色单据、深橙操作色与焦点、浅暖色 Agent 面板落入 theme.css。Tailwind v4 通过 Vite 编译；共享 Button 使用 shadcn 的本地组件组织方式与 Radix Slot/CVA，components.json 提供后续组件生成路径，Lucide 提供图标。组件按产品规范自行实现，没有复制完整外部模板或 Mistral 商标。没有安装无关的按需 UI 库。

工作区表单接入 React Hook Form＋Zod resolver，空名显示可定位错误；服务错误明确展示，冲突不自动重试，提供重新加载入口并展示当前版本。TanStack Query 通过注入 DesktopClient 查询/提交，成功后 invalidateQueries 读取已提交事实；组件不访问存储。提交中禁用按钮，同内容重试复用幂等键，编辑内容或基线版本变化才生成新键。工作区数据不是复制到 UI store 的持久事实源。

单据主视图有空态与明确标记的合成样例，展示商品行、未知价格、金额依据、交易条款、待确认事项、差异与 Agent 区域。样例不写报价数据库，没有虚构 V1/V2 保存结果。人工审核、模型输入与发送按钮均禁用且标注未接入原因。真实 V1 已在独立“资料与报价”页显示保存结果；本页合成布局与 Agent 区仍未接入修订事件。

当前实际 Electron 截图在本地 output/playwright/m1-workbench.png，属于可重建测试产物，不提交客户资料。已检查桌面布局、中文文字与表格，无明显重叠；900px 窗口测试检查无页面横向溢出。键盘焦点、表单错误/冲突在测试中执行；全键盘路径、125%/150% 系统缩放、跨平台视觉与语言输出仍需后续验收。

组件组织参考：[shadcn Button](https://ui.shadcn.com/docs/components/button)。原工作台页仍是 M1 布局验证；新增手工 V1 实际边界见 [[M2真实报价V1]]，不是完整报价 MVP。

## 窗口自适应与图标修正

此前 app-shell 仅 min-height:100vh，文档 min-height:620px，加上头部和 padding 把整个页面撑高；窗口放大也缺乏明确的外壳高度与滚动归属。现在 root 固定到视口并用 overflow:clip 禁止根滚动，app-shell 为 100% 高度，sidebar/main 可收缩，main 独立 overflow:auto；短内容随主区域伸展，长内容及单据表格在 main 内滚动。sidebar 始终到窗口底部，宽度 ≤1000px 成为 76px 图标导航，链接保持 aria-label/title 与可见焦点；长工作区名称最多三行，不把菜单挤出窗口。

真实 Electron 请求 800×640 / 900×800 / 1380×900 / 1920×1080 内容尺寸，macOS 限制后实际为 800×640 / 900×800 / 1380×815 / 1920×815（记录于验证 JSON），分别叠加 100%/125%/150% 应用 zoomFactor。曾在 800×640、150% 下观测 html clientHeight=426、scrollHeight=456；仅改变 Grid 行约束不能消除根溢出，固定 root 并 clip 后根高度一致且无法程序滚动。正文仍可滚动到“发送给 Agent”，没有隐藏超出屏幕的主体内容。应用缩放不等于 Windows/macOS 系统显示缩放验收。

侧栏 TQ 字符替换为项目图标，Main 同步设置 Dock/window 图标，打包用 ICNS/ICO。截图 `output/playwright/m1-layout-wide.png` 与 `m1-layout-narrow.png` 已实际查看，宽屏两列、窄屏图标导航与纵向面板均可用；截图为忽略的合成测试产物。完整系统缩放、读屏与跨平台视觉仍待验收。实现来源为 theme.css、App.tsx、main/index.ts 和 resources/icon.svg；验证见 [[M1验证与协作]]。


## 资料与报价页面

新增 /quotes：四个连续区域为场景配置（RHF/Zod）、CSV 选择/粘贴及预览确认、商品数量与询盘/条款表单、已保存草稿。默认配置可编辑，合成样本须主动填入且再次确认发布；sourceStatus 与待确认/已发布状态可见。查询通过 TanStack Query 调 DesktopClient，写入成功后刷新真实服务；同内容操作在页面存活期间保留幂等键。重复原文导入依据返回 batch ID 选中正确历史批次。

草稿显示来源、档位与单价、未知金额、商品合计（明确未含运税费）、场景快照与待确认事项；保存 V1 后仍禁用正式审核。select 沿用 input token，复用现有 Button、表格横向滚动与 main 独立滚动。没有新增样式库或伪造对话结果。截图与桌面结果在 [[2026-10-21-演示场景与报价V1]]，细节见 [[M2真实报价V1]]。

## 统一 message 与 Notification

用户要求替换页面零散小提示与截图中的整行错误条。App 外层统一挂 MessageProvider；业务通过 useMessage 获取 message.error / message.success。工作区创建/保存、报价写入、CSV 文件选择和报价提交前综合校验改用短提示；原本把成功和错误都放 sample-note 的状态已拆开。错误 6 秒、成功 4 秒，悬停和焦点暂停，重复内容刷新计时，最多 3 条，关闭不清除表单。路由切换仍由 App 中同一个 Provider 管理短提示。

共享 Notification 用于工作台、工作区设置、报价页的查询失败，以及工作区版本冲突；右上角浮层承载标题、原错误说明与重试操作。查询重试中禁用按钮，成功后组件卸载；重要问题持续显示，不提供当前页面的忽略入口。组件可选 onClose 支持非阻断通知。截图中的“调用来源不允许”仍如实显示，此改动未放宽 IPC 来源检查或声称修复其根因。

两组件均 portal 到 body，不改变 main/单据布局；窄窗口限定宽度、长文折行，Notification 限高可滚动；同时出现时 message 移到底部。语义色来自 DESIGN 的 danger/success/border/text-secondary，并补齐到 theme.css。错误为 alert，成功为 status，不抢焦点。字段错误、CSV 行级校验与合成样例说明保留原位。没有新增依赖或跨进程接口/存储变更。

源码：apps/desktop/src/renderer/src/shared/message.tsx、shared/notification.tsx、App.tsx、features/workspace.tsx、features/workbench.tsx、features/quotes.tsx、theme.css。验证与剩余边界见 [[2026-10-21-统一消息与通知]]、[[M1验证与协作]]；报价行为见 [[M2真实报价V1]]。

## 所有页面取消独立页头

用户要求把独占一行的 head 空间还给业务内容，四条路由统一取消英文眉题、页面大标题和宣传说明，页面名由导航表达；保留 sr-only 一级标题供辅助技术使用。主区域 padding 从桌面 36px/28px、窄屏 24px/18px统一为16px；首页单据/助手、资料场景、工作区名称表单、模型连接面板直接从内容起点展示。资料页区块间距统一16px。移除旧 page-heading/eyebrow 样式，避免新页面沿用大页头。

资料页重新加载按钮并入现有“演示场景”标题行，查询或写入期间禁用；工作区版本状态随表单就地显示；DeepSeek 服务名称及接口地址放入连接面板。保留字段说明、合成数据边界、通知与审批状态。只调整renderer布局及局部组件props，不改变DesktopClient/IPC、金额、密钥存储或持久化。来源：features/workbench.tsx、quotes.tsx、workspace.tsx、model-settings.tsx、theme.css与根DESIGN.md；实际桌面和窄屏检查见 [[2026-10-21-取消独立页头]]、[[M1验证与协作]]。

## 只读助手页面

App新增侧栏“只读助手”及/assistant路由，独立read-assistant.tsx复用Button/message/Notification和已有资料查询。首业务面板直接提供授权报价选择、任务输入/提交与刷新，没有独占页头；说明数据会发给已配置模型，知识/规则暂不开放。缺资料/场景、加载/错误/运行中/禁用/澄清/空工具结果均有明确反馈。

## UI 样式优化（2026-10-31）

按用户「整页字要看得清、太小统一调大」「保留橙黄基调但不要大片留白、改浅灰层次」的要求，对渲染层做小样式优化，不涉业务逻辑与品牌主色。

- **图标与 hover**：模型设置导航图标 `Settings`→`Cpu`；`nav a:hover` 加浅灰背景，active 项 hover 不闪烁。
- **字号可读性**：`small` 13px、`label` 14px、`.brand small`/`.sidebar-footer`/`.status-badge` 11→12px、`table` 12→13px。
- **表格表头圆角**：`table` 改 `separate` + `border-radius:8px` + `overflow:hidden`，表头灰底跟随卡片圆角；`.table-scroll` 加 1px 内边距。
- **工作区设置居中**：`panel max-w-2xl` → `panel max-w-md mx-auto my-auto`，收窄并水平垂直居中，消除偏左 + 下方大片空白。
- **暖灰配色层次**：`--canvas #fffaeb→#f2efe9`、`--surface-muted #fafafa→#f5f3ef`、`--border #e5e5e5→#e8e5df`、`--surface-warm #fff8e0→#fff4e0`；白卡片 `.panel` 加淡阴影浮起。橙黄品牌强调（顶边条/按钮/选中态）保留不变。
- **徽章 + 等宽数字 + 过渡**：`.status-badge` 改带圆点胶囊；`.basis` 加 `tabular-nums`；按钮/输入加 120ms 过渡。

改动与验证见 [[2026-10-31-A01-UI样式优化]]。
