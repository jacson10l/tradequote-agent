# C04失败阶段诊断与二轮收敛

后续用户显式运行885c474的真实结果已单独记录于[[C04阶段证据真实复测]]与[[C04-阶段证据真实复测核对]]：31业务23通过/3失败/5跳过、145真实请求，16行17实际枚举事件。原八失败5本次通过/1仍失败/2跳过；本页以下“无真实请求/真实仍待”限定此前本地实现切片，不将本地八合成类倒推为真实根因，不改旧报告。

## 范围与事实边界

从3a476a3新建独立codex/c04-failure-diagnostics，先增加有限枚举诊断，再对[[C04修复分支真实复测]]的八个失败ID重建本地回归、最小修复。旧真实报告仍是82次真实请求、31业务12通过/8失败/11跳过，17故障注入fixture_only。真实动作/参数未保存，所以本轮无法倒推或回放旧失败的具体阶段；不得将新增诊断反填到旧报告。本轮没有真实供应商请求，不读取Key、凭据文件、用户业务库或模型原文，不切换用户仍打开的旧应用。

## 可选诊断契约

EvaluationRow增加可选diagnostics数组，1～12条，仅新的实际观测填入。旧记录缺该字段时不补默认值、不重写历史；旧Markdown在没有diagnostics时保持原格式。FailureDiagnosticSchema为strict对象，工具名复用现有AgentToolNameSchema，模型不能提供此结构或任意诊断文本。

| 字段 | 宿主来源与含义 |
|---|---|
| stage | provider、action_schema、tool_lookup、tool_input、tool_execution、completion、clarification、budget、context之一，按当前执行边界产生 |
| tool | 已注册工具白名单中的真实名称；动作未解析、未知工具或非工具阶段为null，绝不回显模型给的未知名称 |
| category | 固定分类：上游失败、动作形状、未知工具、缺字段/类型/未知字段/非法值/数量格式、缺核价/知识前置、业务失败、提前结束、缺事实、规则阻断、请求/上下文预算、取消/超时 |
| disposition | feedback表示已提供纠正反馈；stopped表示本次结束，不能把曾纠正过当最终失败或把预期阻断当保存成功 |
| modelCall | 当前单次草稿运行已尝试的模型请求序号，0～12；不是累计收费数或工具账本序号 |
| errorCode | 现有公开ErrorCode枚举，不带message、issues或原始异常 |

只依据Zod错误种类和宿主分支生成分类；字段路径只在内存用于归类，路径、未知字段名、输入值、模型回答、summary、工具结果、认证头、Key和错误栈均不进入证据。身份格式错误只标invalid_value，不暴露实际ID。反向测试注入合成秘密字段/值/未知工具名，确保只保留枚举；额外诊断字段或任意字符串拒绝。

## 接线与持久范围

AgentRunCoordinator可注入FailureObserver，传到QuoteToolAgent和ToolLoopRuntime。仅C04评估runner绑定该观察器，把事件投影到当前样本行并最多保留末12条；非评估报价运行不因此新增持久字段。观察器仅接收已通过strict schema的安全投影，其异常被隔离，不改变业务成功/失败、派发或重试。

新诊断随原报告经evaluation worker/Main/ModelEvaluationRun持久化，JSON和Markdown从同一strict报告生成。正式桌面“查看检查明细”增加脱敏失败证据列，显示阶段/工具/分类、反馈或停止及请求序号；旧失败行没有证据则显示“未采集”。原生导出、历史重开和fixture/真实标签沿原路径，不提供新启动、日志或解密接口。

证据覆盖工具循环真实观察到的阶段；工作区准备、运行准入或循环外直接Provider测试等未注入位置可能没有diagnostics，不能推造阶段。它不是逐步原始日志，进程被强杀前尚未形成最终报告时，不保证有诊断报告可回读；没有给业务AgentRun/迁移加字段。公共变更限C04可选字段，复用B既有工具名契约，B非作者复核仍待，不冒称签字。

## 最小修复和仍然拒绝的情况

沿用[[0024-同次草稿运行内受限纠正]]的同run/attempt共享一次额度、12次模型/工具上限、120秒和上下文预算，只扩三个可纠正入口：已实际读取商品/基线后提前complete；宿主确认缺核价或“候选ID正确但尚未读知识”的前置步骤错误；calculate_quote内proposal.lines/patches的quantity格式错误。反馈为固定引导，模型须按原schema重交，没有自动改数字、填事实、执行缺失工具或保存。

未读取资料的虚假完成仍直接失败；错误/过期候选ID、UUID格式、写授权/版本冲突、未知工具、未知字段/金额注入、零数量、业务失败、Provider首错、取消及超时保持拒绝。即使混入一个可纠正数量格式，额外字段仍整体硬失败。第二次重复顺序错误用尽共享额度后结束，不新建attempt；同键重放不发请求。只读助手不启用纠正，规则block/真正缺事实仍保留原结果。

新本地回归包含五项停止边界（错误候选、非法身份、零数量、格式混金额字段、重复顺序），并验证观察器抛异常仍不改变合法提交、未知名称/字段值不进入证据；旧金额/来源/事务/15点SIGKILL和14项前轮停止回归保持。具体命令和结果见[[C04-失败阶段证据与八项回归]]，选型见[[0025-枚举失败证据与前置步骤纠正]]。
