# 知识库可靠性与覆盖范围

> 2026-10-21 本轮增量见 [[M0平台验证记录]] 与 [[0004-M0平台与执行器选型]]：新增真实 Electron/SQLite/解析/PDF/设置页探针；Harness 在当前 Electron 版本失败，默认切最小执行器。下文原 M0-reuse 结果保留其历史作用域。安装/双平台验收按用户决定暂缓。


证据分四类：代码可直接观察的行为、既有运行记录、用户/方案决定、待验证推断。当前文件大多未提交，因此语义页标 observed 或 active；不凭路径/hash 自动升级 verified。

已完整阅读本轮范围内的根规则/README/DESIGN、实验 manifest、业务桥接、Harness 探针、收集器、11 个刻画用例，以及两个原样 Solivio 文件。已检查复用来源、许可证与合成证据结构。锁文件读取 importer/版本覆盖及头尾/依赖边界，完整 bytes 纳入 hash；未逐行解释约九千行的传递依赖解析，没有深读 node_modules 或上游全仓。

[[源码覆盖矩阵]] 为每个纳管文件分配真实职责页；覆盖代表可追溯，不等于测试覆盖率或安全审计率。[[代码清单]] 行数包含文档/锁文件/证据；必须与业务代码量区分。[[源码快照]] 保存内容 SHA-256、固定 ingest 基线与维护工具指纹。

生成器排除 Wiki 自身、依赖、临时/构建内容、凭据及数据库；日志默认不读，只纳管 config 显式登记的合成 evidence。新文本源码无映射时退出失败；未知类型只记录排除政策，新增类型需先扩展扫描规则。全部符号链接不跟随，项目外 Wiki 或输出 symlink 会失败。

机械运行时清单不展开依赖包或动态注册，包脚本可完整枚举但路由/工具/事件是模式匹配。生成器不依据 Git 当前 HEAD 判漂移；显式 ingest 更新基线，普通 generate/--check 比较实际内容。临时目录/依赖存在与否不影响生成快照。

原始输入/设计保持逐字归档，来源 manifest 中旧规划期观察单独保留；历史 planning-checks/docs-check 只说明当时快照。Wiki 工具自身在脚本测试和指纹中受控，不递归进入业务覆盖矩阵。门禁局限与人工核查方法见 [[Wiki 工作流与任务记录]]，实际已测/未测见 [[测试与验证地图]]。
