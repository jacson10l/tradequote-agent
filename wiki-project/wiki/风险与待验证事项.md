# 风险与待验证事项

> 2026-10-21 本轮增量见 [[M0平台验证记录]] 与 [[0004-M0平台与执行器选型]]：新增真实 Electron/SQLite/解析/PDF/设置页探针；Harness 在当前 Electron 版本失败，默认切最小执行器。下文原 M0-reuse 结果保留其历史作用域。安装/双平台验收按用户决定暂缓。


| 风险/缺口 | 现有依据 | 后续动作 |
|---|---|---|
| 真实模型能力未知 | 只有 Messages SSE fixture | C 配置真实模型，验证工具 schema、语言、限流、取消 |
| Windows/打包未验证 | 探针依赖 Unix ps，无安装包 | C/A 补两平台真实安装与 runtime 路径/原生模块 |
| 宿主重启丢失业务状态 | revision/幂等在内存 | A/B 完成事务、唯一约束、事件与恢复测试 |
| 上游 preview 与体积 | runtime/client 0.2.1-rc.2，较大依赖树 | 锁版本，打包测体积；不能用禁用 profile 代替裁剪 |
| 取消影响共享进程 | 无单会话取消方法 | 一个活动 run 独占进程；超时也须回收 |
| 解析/金额/locale | 上游刻画存在契约差异 | A/B 用选定库实现业务校验和可配置映射 |
| 第三方/字体分发 | 当前只保留已复制文件许可 | 安装包形成时汇总全部分发许可 |
| Wiki 自动检查边界 | 正则抽取、hash/引用/图结构检查 | 人工回源码确认语义；新文件漏分类必须失败 |

M0 G0 已完成技术评估；G1 部分通过，G2/G3 未完成。Wiki 门禁成功不改变这些产品关卡状态。完整产品演进风险在 [[07-服务器演进与风险]]，当前验证地图见 [[测试与验证地图]]，复用决定见 [[0002-上游复用方式]]。
