# 模型服务设置验证

本文记录 M0 独立验证页；正式应用最新入口、存储与边界见 [[M4模型与报价修订]]，本页历史流程不自动迁移凭据。

按用户要求，API Key 在桌面系统设置中输入，不要求发到聊天或写入仓库环境文件。启动 `pnpm --dir experiments/m0-platform settings`。

流程：保存 Key → 测试连接获取账户模型列表 → 选择模型并保存 → 验证模型。网络只由主进程访问官方 `https://api.deepseek.com`；renderer 没有 Node 与联网权限。每个 IPC 校验调用窗口/主 frame/URL；保存字段 strict。API Key 字段在提交后清空，读取配置只返回 hasKey/model/storage。

系统 safeStorage 可用时写入 userData 的加密文件，不可用则仅内存使用；解密失败明确要求重新配置。实际用合成 Key 验证密文不含原文、store 重新初始化可解密、页面不回显。正式签名/升级的稳定应用身份仍待验收。当前为 M0 独立 HTML 页，M1 迁入 React/TypeScript 设置模块，不能称完整产品设置完成。

`/models` 获取实际可用型号，不用文档例子冒充账户型号；`/chat/completions` 的 JSON 测试只发送公开合成内容，并在 UI 明示会调用模型。错误归类为认证、限流、超时、空/无效输出、连接失败，日志不写认证头/返回全文。连接结果保存 model-validation.json 到 userData，不含 Key。当前未提供流式、工具能力全评估与可编辑代理端点。

用户真实配置由页面处理；本轮没有读取真实 Key 或宣称已调用真实 DeepSeek。真实结果只有在用户执行页面测试后才能登记。

官方依据：[模型发现](https://api-docs.deepseek.com/api/list-models/)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)、[safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage)。
