# M0契约评审准备

T00 的评审材料已准备，三名实际开发者的评审尚未发生。A 数据、B 领域、C 桌面仍按原分工确认；不把 AI 自检称为三人同意。

| 边界 | 必需字段/不变量 | 本轮证据 / 尚需确认 |
|---|---|---|
| 数值 | DecimalString、Quantity.value/unitId；未知不等于 0 | strict schema 与拒绝科学计数/数字型测试；数量精度范围须统一 |
| 修订命令 | quoteId、baseRevisionId、expectedAggregateVersion、typedPatch、reason | 子集仅 setQuantity/selectPrice；其余 7 类 patch 待实现 |
| 宿主上下文 | workspaceId、actor、requestId、idempotencyKey、origin、runId | 不接受模型伪造；键按 workspace/command/operation 分域，探针固定单工作区只验证机制 |
| 不可变快照 | inquiry/product/price/config/rules/FX/terms 来源版本、parent/seq/contentHash | 文档已列全；探针不覆盖完整快照及 canonical JSON |
| 事务提交 | 新 revision/check/task/citation/outbox/idempotency＋当前指针 | 原子 revision/outbox/key 已实测；其余关联表留 M1 |
| 审批 | revisionId、contentHash、bundleHash、人工身份、当前 aggregateVersion | 三字段 schema；人工权限、重新校验和完整审批服务待 M3 |
| 产出 | artifactId、revisionId、locale、template/terms revision、bundleHash | 输入 PDF 为合成内容；正式 public projection 待实现 |
| 来源 | sheet/cell、CSV 物理行与逻辑记录、PDF page/span/bbox、DOCX paragraph/table/cell | 基本样本提取通过；CSV 多行起止范围与 DOCX 复杂位置需定稿 |
| 运行事件 | schemaVersion/eventId/runId/seq/timestamp/type/payload | 完整 type 判别 schema 待实现；至少一次投递、重连补序号、eventId 去重沿用设计 |

错误清单沿用接口页的 18 个错误码；本轮实测 VALIDATION_ERROR、REVISION_CONFLICT、IDEMPOTENCY_CONFLICT、存储回滚、MODEL_AUTH_FAILED、MODEL_RATE_LIMITED、MODEL_TIMEOUT、MODEL_INVALID_OUTPUT、CANCELLED。工具预算/未授权工具为探针内部错误，正式 adapter 必须映射到公开 Result，不直接扩散字符串异常。

需要三人逐条确认：同键同参必须返回旧结果，即便 expectedVersion 已过期；同键异参冲突；写成功但取消不能撤销已提交版本；旧 bundle 审批不能覆盖新语言产出；Agent 不可审批；source 失效和 unknown 保存后不可被误标为正式可导出。
