## 独立分支是开工前置条件

每位成员使用独立clone，或各自独立worktree；禁止三人共用同一工作目录切分支。禁止在main或codex/m1-foundation直接做成员功能。一个分支只承载一个任务/小切片；不共享feature分支、不强推他人分支。

新同事首次获取：

```sh
git clone https://github.com/jacson10l/tradequote-agent.git
cd tradequote-agent
git fetch origin
# A执行；B/C将分支名替换为上表对应名称
git switch --no-track -c codex/a01-knowledge-publish origin/codex/m1-foundation
git rev-parse HEAD
```

将最后输出记录到自己任务页为taskBase，记录OS/CPU/Node/pnpm和领取人。已经有仓库者先检查 `git status --short`，未提交工作先在原任务保存，不能用reset/clean清掉；已有同名任务分支就继续该分支，不覆盖重建。B00合并后，B从更新的集成分支另开B01，不能把未合入的契约隐藏在大功能PR里。

每天集成前抓取远端；已有发布分支优先merge共享分支，避免需要force push：

```sh
git fetch origin
git merge origin/codex/m1-foundation
# 完成代码、Wiki和测试后再正常提交/推送自己的分支
git push -u origin HEAD
```

PR目标为codex/m1-foundation，C汇总集成；成员不得自行把目标改main。非作者评审通过并核对适用平台本机检查/Wiki证据后合入；main的后续合并另行安排。用户已停用仓库Actions和云端测试，当前以macOS本机记录推进需求开发和PR，Windows验证后置、不阻塞当前合入，不能假定服务端自动门禁存在。
