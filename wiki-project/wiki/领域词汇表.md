# 领域词汇表

| 术语 | 产品含义 | 当前实现状态 |
|---|---|---|
| 商品/商品版本 | 跨品类 schema 下的属性与来源 | fixture 只有固定阀门，产品层未实现 |
| Evidence | 支撑价格/属性/规则的版本化来源 | fixture 使用合成 evidenceId |
| Calculation | 由确定性代码得出的金额与依据 | Decimal 算式已用；两种策略/trace 未完成 |
| QuoteRevision | 不可变报价草稿快照 | 实验是内存对象；持久化契约见原方案 |
| expectedVersion | 拒绝过期提交的并发前提 | 实验检查数组长度，无并发事务 |
| Idempotency key | 宿主分配、同操作重复提交复用结果 | 实验固定键＋Map，不是模型参数 |
| AgentRun | 一次受控执行活动及业务关联 | 探针运行演示；产品 run 表未实现 |
| Session | Harness 持续对话与历史 | JSONL 与 sessionId；不等同于业务版本 |
| Approval | 人工对指定版本/产出进行审核 | 没有模型审批工具，审核产品尚未实现 |
| Wiki | 工程知识库 | 本仓库 wiki-project；与未来企业业务知识分开 |

同名术语在上游与本项目中可能不同。SDK finalResponse 是活动期间的最后助手文本，不能作为报价已经保存的事实；产品须以服务提交结果为准。精确 DTO 以 [[03-领域与数据契约]] 为权威，端口见 [[04-接口与Agent契约]]；当前状态见 [[项目状态]]。
