# 数据持久化与状态

当前C01b准备明确复用现有单连接，将run完成与quote/turn/outbox/idempotency放同一IMMEDIATE事务；运行控制幂等独立于旧TradeResult缓存，取消按attempt/executionId隔离，重启只标interrupted。建议表、A的迁移前驱校验和内部提交核心方案见 [[C01b存储接口与事务方案]]。目前没有新增这些表或迁移，不把 [[C01b恢复测试用例]] 的设计当真实恢复已通过。

> 2026-10-21 本轮增量见 [[M0平台验证记录]] 与 [[0004-M0平台与执行器选型]]：新增真实 Electron/SQLite/解析/PDF/设置页探针；Harness 在当前 Electron 版本失败，默认切最小执行器。下文原 M0-reuse 结果保留其历史作用域。安装/双平台验收按用户决定暂缓。


| 状态 | 当前所有者/存储 | 恢复边界 |
|---|---|---|
| revision 列表、calculation | 探针宿主数组/变量 | 宿主退出即丢失 |
| 业务幂等 | 宿主 Map，固定 trustedOperationId | 只验证 runtime 重启；不是数据库唯一约束 |

| profile/bridge token | 临时目录与子进程环境 | token 由随机值生成，不提交到证据 |

`experiments/m0-reuse/harness-probe.mjs:56` 在业务端点检查 expectedVersion，并按宿主操作键去重；未实现持久化事务、outbox、迁移、备份或并发隔离。重复写入检查只覆盖同一 payload 场景；异 payload 同 key 与多客户端竞争仍需要未来领域/存储契约测试。

本轮无数据库表、SQL schema、迁移文件、持久化任务队列；SQLite/better-sqlite3/Drizzle 仍为基线选择，不能伪造其运行结果。未来 immutable revision、审批绑定与恢复规则见 [[03-领域与数据契约]]。

运行数据路径与不入库内容见 [[配置路径与敏感信息]]；取消和恢复测试的真实边界见 [[核心业务流程]]。

## M1 正式持久化

工作区真实库位于 userData/workspaces/default/workspace.sqlite，单业务进程写入，初始 workspace/source/job/idempotency/outbox 五表。工作区、幂等和事件同事务提交；版本冲突拒绝覆盖。Drizzle adapter、迁移回滚/高版本拒绝、ArtifactStore 与消费恢复边界见 [[M1接口与持久化]]。M0 引用继续作为历史实验，不把备份探针能力直接当成产品已接入。


## 正式场景、CSV 与报价快照

迁移 2 增加场景版本、CSV 批次及原文、已发布商品、不可变 QuoteV1；报价冻结依据并保存 hash，禁止 UPDATE/DELETE，旧配置不随新配置改变。仍为单 worker 同一连接写入，事件失败回滚全部业务写入，幂等与重开已有测试；原 source/job 表尚未整合为通用导入作业。本文上方内存状态属于 M0 历史探针，不是当前正式报价存储。详见 [[M2真实报价V1]]、[[M1接口与持久化]]。


## 正式模型与两轮修订增量

迁移3保留quote_v1，quote_revision新增root_id/parent_id/version/hash/json和唯一约束；agent_turn冻结用户请求、summary/model/time与版本关联。模型等待在事务外，返回时校验当前版本再原子写quote/turn/outbox/idempotency。不可UPDATE/DELETE，先查已成功幂等再调用模型；未提交/失败对话不保存，完整AgentRun/job恢复仍待后续。 细节与当前边界见 [[M4模型与报价修订]]，本轮验证见 [[2026-10-21-正式模型与两轮修订]]。
