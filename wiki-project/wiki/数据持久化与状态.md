# 数据持久化与状态

> 2026-10-21 本轮增量见 [[M0平台验证记录]] 与 [[0004-M0平台与执行器选型]]：新增真实 Electron/SQLite/解析/PDF/设置页探针；Harness 在当前 Electron 版本失败，默认切最小执行器。下文原 M0-reuse 结果保留其历史作用域。安装/双平台验收按用户决定暂缓。


| 状态 | 当前所有者/存储 | 恢复边界 |
|---|---|---|
| revision 列表、calculation | 探针宿主数组/变量 | 宿主退出即丢失 |
| 业务幂等 | 宿主 Map，固定 trustedOperationId | 只验证 runtime 重启；不是数据库唯一约束 |
| 会话与消息 | Harness dshHome 下 JSONL | 关闭后使用同一目录和 sessionId 恢复 |
| 合成请求摘要 | 宿主内存，结束写 evidence | 不存认证头；全部是合成业务数据 |
| profile/bridge token | 临时目录与子进程环境 | token 由随机值生成，不提交到证据 |

`experiments/m0-reuse/harness-probe.mjs:56` 在业务端点检查 expectedVersion，并按宿主操作键去重；未实现持久化事务、outbox、迁移、备份或并发隔离。重复写入检查只覆盖同一 payload 场景；异 payload 同 key 与多客户端竞争仍需要未来领域/存储契约测试。

本轮无数据库表、SQL schema、迁移文件、持久化任务队列；SQLite/better-sqlite3/Drizzle 仍为基线选择，不能伪造其运行结果。未来 immutable revision、审批绑定与恢复规则见 [[03-领域与数据契约]]。

运行数据路径与不入库内容见 [[配置路径与敏感信息]]；取消和恢复测试的真实边界见 [[核心业务流程]]。
