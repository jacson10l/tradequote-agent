# 演示数据包清单（demo_data）

本目录为演示（demo）报价闭环的目录数据包。按 C 的演示冻结要求：**主演示只用已验证小样本，300 行混合币种目录暂不作为主演示。**

## 文件与角色

| 文件 | 角色 | 说明 |
| --- | --- | --- |
| `catalog_demo.csv` | **主演示（冻结）** | 14 行、4 个 SKU 的小样本，覆盖 3 品类 × 2 币种 × 3 单位 × 阶梯价 |
| `catalog_converted.csv` | **备用、非主演示** | 300 行、86 个 SKU 的全量目录，仅作备用与扩充源 |

覆盖：3 大类目（服装 / 板材 / 紧固件）、2 币种（CNY / USD）、3 单位（piece / m² / kg）、阶梯定价（4 档 / 3 档）。

## 合成来源说明（重要）

- 本目录**全部为合成数据**，非真实客户订单、成交记录或供应商真实报价。
- 每行 `description` 末尾固定携带「供应商 / 来源(URL) / 采集日期」三段，即合成来源标注：
  - 服装类采集日期 2026-10-21（来源为 alibaba 产品页合成 URL）；
  - 板材 / 紧固件采集日期 2026-10-29（来源为 `_16000000XX.html` 合成 URL）。
- 不含真实 API key、客户原始数据、运行库、安装包或敏感日志。

## 冻结约定

- `catalog_demo.csv` 为演示当日冻结版本，未经 B 规则复核不得改动；如需替换 SKU，须重新验证后再次冻结。
- `catalog_converted.csv` 保留为备用与扩充源，不直接作为主演示。
