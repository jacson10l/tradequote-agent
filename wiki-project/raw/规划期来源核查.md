## 设计参考

实际执行：

```text
npx --yes getdesign@latest add claude
npx --yes getdesign@latest add mistral.ai --force
```

第二条依据用户后续更正替换第一条；`--force` 只替换本轮生成且已归档的根 DESIGN.md。实际缓存包为 getdesign 0.6.26，包 metadata 标记 MIT。

当前原始来源：[Mistral 模板](design/mistral-original.md)、[对应目录页](https://getdesign.md/mistral.ai/design-md)。历史来源：[Claude 模板](design/claude-original.md)，只用于记录已被替换的选择。根 [DESIGN.md](../../DESIGN.md) 是经过产品适配的规范。

目录页摘要仍写紫色风格，实际 CLI 返回的模板是橙/黄/奶油色；本项目以归档文件为准。未取得模板远端固定 commit，不编造其 revision；以 CLI 版本、执行命令、采集日期与文件 hash 保证本次来源可追踪。
